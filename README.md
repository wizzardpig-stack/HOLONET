# HOLONET

An interactive semantic knowledge map for exploring connected ideas as a spatial network. HOLONET combines graph navigation, guided paths, debate framing, saved destinations, and contextual chambers inside one explorable interface.

## Live

https://wizzardpig-stack.github.io/HOLONET/

## What it demonstrates

- Large interactive knowledge graph with DOM nodes and Canvas-rendered edges
- Pan, zoom, filtering, search, guided paths, and contextual detail panels
- Performance-oriented graph architecture that avoids per-edge DOM/SVG overhead
- Touch-specific node sizing and collision spacing on mobile devices
- Responsive removal or simplification of secondary desktop UI on smaller screens
- Reduced-motion support and mobile boot/performance reductions

## Stack

HTML, CSS, vanilla JavaScript and Canvas.

## Development approach

Independent product architecture, information design, interaction design, performance iteration, QA, and AI-assisted implementation. HOLONET is an experimental knowledge interface rather than a conventional content site.

## Current status

Public prototype. The repository build is being treated as the current deployment candidate while version provenance is rechecked against the latest local release file.
